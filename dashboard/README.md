# Dashboard specification

## Retention risk dashboard

**KPI cards:** Customers · Churn rate · Churned customers · Monthly charges exposed

**Risk segments:** Churn rate by contract and tenure band

**Exposure:** Monthly charges associated with customers already labeled as churned

**Diagnostic:** Churn rate by payment method

**Action panel:** Prioritize high-churn segments while distinguishing observed exposure from a predictive revenue forecast.

The dashboard is designed for Power BI after loading the IBM public Telco Customer Churn CSV into PostgreSQL.
